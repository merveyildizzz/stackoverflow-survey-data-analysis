# Stack Overflow Developer Survey Analysis

## 📊 Project Overview
Data analysis project using the Stack Overflow Developer Survey dataset. Includes data cleaning, exploration, and business insights using Python and Pandas.

---

## 🛠 Tools & Technologies
- Python
- Pandas
- Jupyter Notebook

---

## 📌 Key Analyses

- Total number of respondents
- Missing data analysis
- Work experience (mean, median, mode)
- Remote work distribution
- Python usage percentage
- Online learning trends
- Salary analysis by country (Python users)
- Top earners analysis
- Age-based Python usage
- Industry analysis of high-income remote workers

---

## 📈 Key Insights

- Approximately 37% of respondents reported using Python, confirming its strong position among programming languages.
- Remote and hybrid work models are widely adopted across the dataset.
- High-income remote roles are heavily concentrated in software development.
- Python usage remains consistent across most age groups, indicating broad adoption.
